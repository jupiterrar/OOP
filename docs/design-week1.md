**1. Перечень методов хранилища с сигнатурами и семантикой (что возвращает, что кидает, что гарантирует)**
  1) def save(self, task_id: Task) -> None:
    Сохраняет Task и добавляет его в текущее хранилище.
    На выходе выдает либо None (только сохраняет результат), если операция выполнена успешно, либо ошибку (DuplicateTaskId, StorageError)
    Один и тот же экземпляр Task можно сохранить в двух разных бэкендах, это не будет являться ошибкой. Добавление Task в одно хранилище не добавляет его в другое.
  
  2) def get(self, task_id: str) -> Task:
     Возвращает указанный Task или ошибку, если она возникла (TaskNotFound, StorageError)
    
  3) def delete(self, task_id: Task) -> None:
     Удаляет Task из текущего хранилища.
     На выходе выдает либо None (только сохраняет результат), если операция выполнена успешно, либо ошибку (TaskNotFound, StorageError)
     Удаление Task из одного хранилища не удаляет его из другого.
    
  4) def list_all(self, filter: Optional[TaskFilter] = None) -> List[Task]
     Возвращает список всех Task из текущего хранилища или ошибку, если она возникла (StorageError).
     Не затрагивает объекты другого хранилища.

**2. Список инвариантов Task**

  1) Immutable (неизменяемый)
  2) id (str, UUID4) != null
  3) 1 <= title (str) <= 200
  4) status ∈ {"todo", "in_progress", "done"}
  5) created_at (datetime, UTC, timezone-aware) != null
  6) tags ∈ tags_list
  7) 1 <= priority (int) <= 5

**3. Явное решение: какие операции идемпотентны (save существующего id — ошибка или upsert? зафиксируйте решение)**

  Идемпотентные операции: get, list_all.
  Save существующего id - ошибка (наши Task неизменяемы)
  Повторный Delete вызовет ошибку (TaskNotFound)

**4. Что означает list_all(filter=None) — все задачи или пустой список**

  list_all(filter=None) - все задачи в текущем хранилище. filter=None означает, что мы не фильтруем этот список по каким-либо параметрам.
